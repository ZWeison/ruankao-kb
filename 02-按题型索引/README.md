> **请勿手工编辑** —— 改动会在下次生成时丢失。
> 要新增内容，请修改 `01-真题-按年份/` 下的正文，然后重新运行脚本。

---

## 本目录的作用

`01-真题-按年份/` 是**正本**（按考期保真归档）。
本目录是**视图**（同一批题的另一种排列方式），**只放索引和统计，不复制正文**。

这样设计的理由：**一道题永远只有一个正本**，不会出现"两个版本答案打架"。

## 文件清单

| 文件 | 内容 | 典型用法 |
|---|---|---|
| `选择题-按考期.md` | 所有综合知识卷，按年份倒序 | 找某一年的选择题 |
| `案例题-按考期.md` | 所有案例分析卷 | 找某一年的案例题 |
| `论文题-按考期.md` | 所有论文卷 | 找某一年的论题 |
| `考点覆盖统计.md` | 标签频次 + 年份×科目覆盖矩阵 | **找薄弱考点**、看整体归档进度 |

## 常用检索（Obsidian 搜索框直接粘）

```
# 找所有含"架构评估"标签的卷
["考点标签" 架构评估]

# 找答案存疑的卷（需要重点核对的那批）
["答案可信度" 存疑]

# 找还没校对的
["校对状态" 待校对]

# 找模拟题（确认它们没混进真题目录）
["来源类型" 模拟题]
```
