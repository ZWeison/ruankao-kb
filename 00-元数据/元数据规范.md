# 元数据规范（v1）

> 本文件是**唯一规范源**。所有真题、范文文件的头部 YAML 必须遵守本规范，
> 否则 `_脚本\validate.py` 会报错、`_脚本\build_index.py` 无法收录。

---

## 1. 为什么要有元数据

一套没有元数据的真题，就是一堆文件。有了元数据之后：

| 能力 | 依赖的字段 |
|---|---|
| 按标签检索（"所有考过 ATAM 的案例题"） | `考点标签` |
| 统计考点分布、生成高频表 | `考点标签` |
| **防止把模拟题当真题背** | `来源类型` + `是否官方` |
| **防止把网友自答的错答案当标准答案** | `答案可信度` + `含解析` |
| 按考期组卷（三科连考模拟） | `年份` + `考期` |
| 溯源与复核 | `出处` + `URL` + `抓取日期` |
| 控制质量（哪些还没校对） | `校对状态` |

## 2. 文件命名与存放位置

### 2.1 考试期次目录
```
01-真题-按年份/YYYY-考期/
```
| 字段 | 取值 | 示例 |
|---|---|---|
| `YYYY` | 4 位年份 | `2025` |
| `考期` | `上半年` 或 `下半年` | `上半年` |

示例：`01-真题-按年份/2025-上半年/`

> **注意**：2016—2022 年、2023 年只在**下半年**开考，不要凭习惯建"上半年"目录。
> 开考情况以 `考试期次总表.md` 为准。

### 2.2 真题文件命名
```
YYYY-考期-科目.md
```
| `科目` | 含义 |
|---|---|
| `综合知识` | 科目一，75 道选择题（机考） |
| `案例分析` | 科目二，5 选 3 问答题（与综合连考） |
| `论文` | 科目三，4 选 1 论文题 |

示例：`2025-上半年-综合知识.md`

**同一考期出现多套独立回忆版时**，在末尾加版本标记，且**绝不合并**：
```
2023-下半年-综合知识-回忆版A.md      # 65 题
2023-下半年-综合知识-回忆版B.md      # 75 题
```
> 机考后回忆版可能题序、题量、题干都不同。合并会造出"第三个版本"，是错的。

### 2.3 论文范文文件命名
```
03-论文范文/主题目录/NNN-论题简称.md
```
示例：`03-论文范文/05-微服务与云原生/001-论微服务架构及其应用.md`

主题目录清单见 `03-论文范文/README.md`。不确定主题就放 `99-未分类`，别硬猜。

### 2.4 原始资料
`04-原始资料/` 下的 PDF、PPT、视频**只读不改**。这些是凭证。
Markdown 正文若与 PDF 冲突，以"重新核对 PDF"为准，并在 `校对状态` 标 `存疑`。

## 3. 真题文件头部字段（完整 15 个）

每个真题 `.md` 文件**必须以 YAML front matter 开头**，字段名用中文，取值用下面规定的枚举：

```yaml
---
年份: 2025
考期: 上半年
科目: 综合知识
题量: 60
题目类型: 选择题
来源类型: 回忆版
是否官方: false
含答案: true
答案可信度: 高
含解析: true
考点标签: [质量属性, ATAM, Lambda架构, 设计模式]
出处: 博客园 BitX
URL: https://www.cnblogs.com/BitX/p/19045006
抓取日期: 2026-10-11
校对状态: 待校对
---
```

### 3.1 字段说明与取值枚举

| 字段 | 必填 | 类型 | 取值 | 说明 |
|---|---|---|---|---|
| `年份` | ✅ | 整数 | 2009—2026 | 考试年份 |
| `考期` | ✅ | 枚举 | `上半年` / `下半年` | 与目录名一致 |
| `科目` | ✅ | 枚举 | `综合知识` / `案例分析` / `论文` | 与文件名一致 |
| `题量` | ✅ | 整数 | 正整数 | 实际收录的**题/大题/论题**数 |
| `题目类型` | ✅ | 枚举 | `选择题` / `案例题` / `论文题` | 由科目决定：综合知识→选择题，案例分析→案例题，论文→论文题 |
| `来源类型` | ✅ | 枚举 | `真题` / `回忆版` / `模拟题` | **最关键字段**，见 3.2 |
| `是否官方` | ✅ | 布尔 | `true` / `false` | 官方从未公布过真题，**实际只会是 false** |
| `含答案` | ✅ | 布尔 | `true` / `false` | 正文里是否真的有参考答案 |
| `答案可信度` | ✅ | 枚举 | `高` / `中` / `存疑` | 见 3.3 |
| `含解析` | ✅ | 布尔 | `true` / `false` | 是否有解题分析（不只是答案） |
| `考点标签` | ✅ | 列表 | 见 `考点标签词表.md` | 2—6 个，用于按主题检索 |
| `出处` | ✅ | 文本 | 站点或作者名 | 人类可读的来源 |
| `URL` | ✅ | 文本 | http(s) 链接 | 原始地址；本地 PDF 填 `local:文件名` |
| `抓取日期` | ✅ | 日期 | `YYYY-MM-DD` | 抓取/入库日期 |
| `校对状态` | ✅ | 枚举 | `已校对` / `待校对` / `存疑` | 见 3.4 |

### 3.2 `来源类型` —— 最重要的一列

| 取值 | 含义 | 使用建议 |
|---|---|---|
| `真题` | 官方公开卷面（**本领域几乎不存在**，2023 机考后尤其） | 可当权威练习 |
| `回忆版` | 考生考后回忆整理，题序可能被打乱 | **主流可用材料**，但要接受题面不完整 |
| `模拟题` | 机构/个人自命题 | **练习用，绝不能当真题背** |

> **为什么这条要写死**：2023 下半年改机考后，题序打乱、无纸质卷流出。
> 已核实的从业者原话是"机考后真题不好拿出来，所有市面上真题较少，几乎没有"。
> 凡宣称提供 2023 之后"完整权威真题"的，都应当怀疑。

### 3.3 `答案可信度` 判定标准

| 取值 | 判定条件 |
|---|---|
| `高` | 有解析、且与至少两个独立来源交叉一致；或引自教材原文 |
| `中` | 有答案但来源单一；或解析较简略 |
| `存疑` | 作者自答且自带疑问标注（如"这个有疑问""答案更像是这个？"）、或跨来源答案冲突 |

**存疑的题必须在正文里显式标注**，例如在题号后加 `【存疑】`。

### 3.4 `校对状态`

| 取值 | 含义 |
|---|---|
| `待校对` | 刚入库，未人工核对 |
| `已校对` | 已与至少一个独立来源逐题核对 |
| `存疑` | 核对后仍有冲突，需进一步确认（同时应在正文标注冲突点） |

## 4. 论文范文文件头部字段（10 个）

```yaml
---
范文类型: 范文
论题: 论微服务架构及其应用
对应年份: 2021
对应考期: 下半年
主题: 微服务与云原生
字数: 2500
是否考场原文: false
出处: 博客园 garvenc
URL: https://www.cnblogs.com/garvenc/p/19080673/ruankao_system_architect_essay
抓取日期: 2026-10-11
校对状态: 待校对
---
```

| 字段 | 必填 | 取值 | 说明 |
|---|---|---|---|
| `范文类型` | ✅ | `范文` / `模板` / `提纲` | `模板`=空壳结构，`提纲`=只列要点 |
| `论题` | ✅ | 文本 | 完整论题名 |
| `对应年份` | ✅ | 整数或 `未知` | 该论题是哪一年考的 |
| `对应考期` | ✅ | `上半年`/`下半年`/`未知` | — |
| `主题` | ✅ | 见 `03-论文范文/README.md` 主题清单 | 决定放在哪个子目录 |
| `字数` | ⚠️ | 整数或 `未知` | 正文实际字数（不含头部） |
| `是否考场原文` | ✅ | `true` / `false` | **机构自产范文必须填 false** |
| `出处` | ✅ | 文本 | — |
| `URL` | ✅ | 文本 | — |
| `抓取日期` | ✅ | 日期 | — |
| `校对状态` | ✅ | 同 3.4 | — |

> **为什么要有 `是否考场原文`**：已核实多个"范文分享"实为培训机构或机构号自产，
> 题目是真的、文章不是考场答卷。可用于学**行文结构**，不可当**得分样本**。

## 5. 校验与索引

建完文件后运行（在 `D:\软考知识库` 下）：

```powershell
python _脚本\validate.py        # 校验所有文件头部是否合规
python _脚本\build_index.py      # 生成 02-按题型索引\ 与 exams.json
```

`validate.py` 会检查：
- 头部是否存在、15 个字段是否齐全
- 枚举取值是否合法
- 文件名 / 目录名 / 头部三者是否一致（年份、考期、科目）
- 同一「年份+考期+科目」是否重复（重复即报错）
- 考期是否真实存在（查 `考试期次总表.md` 里的开考表）

---

## 6. 三条硬规则

1. **不要合并不同回忆版。** 独立版本各自成文件。
2. **不要把模拟题放进 `01-真题-按年份`。** 模拟题只能进 `99-待校对` 或单独目录，且 `来源类型` 必须是 `模拟题`。
3. **不要修改 `04-原始资料` 下的文件。** 那是凭证，改了就没法回溯。
