## ⚠️ 三个必须知道的限制

### 1. `是否考场原文` 全部为 `false`

那批范文带「历年真题」标注、论题也像真题，但**无法确证是否为考场答卷** ——
公开流传的范文多来自机构或个人整理。按保守口径全部标 `false`。

**只学行文结构与论证方式，不要当作得分样本。**

### 2. `对应年份` / `对应考期` 全部为「未知」

PDF 里**没有标注对应哪一年哪一期**。强行按论题去比对历年真题会引入错误，所以留空。

技术上也难自动比对：`01-真题-按年份/` 里的论文卷只有 2016—2026，
而这批范文以 2009—2016 为主，年份区间基本不重叠。

## 转换方法（可复现）

```powershell
python _脚本\probe_pdf.py       # 1. 探测 PDF 是否含文本层
python _脚本\import_essays.py   # 2. PDF → Markdown，自动分主题
python _脚本\validate.py        # 3. 校验头部合规
python _脚本\build_index.py     # 4. 重建选题索引
```

**转换时踩过的两个坑（已在脚本里修掉）：**

1. **论题不能取「第一个非空行」** —— PDF 首行常是页眉（`x 企业集成平台`、`历年真题`）。
   正确做法是按优先级找「试题N 论XXX」或独立的「论XXXX」行。
2. **主题判定不能把论题和正文混在一起匹配** —— 否则「论SOA技术的应用」会因为正文提到
   「安全」而被判成信息安全。必须**先看论题**。
