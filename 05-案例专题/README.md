## 每篇的结构

```
# 案例题型 NN · 题型名
  ## 考点分布            ← 这题怎么考、多少分
  ## 核心知识点速查       ← 必背表格
  ## 答题模板            ← 按「问题类型」给标准答法
  ## 万能高分句          ← 能直接抄进卷子的句子
  ## 常见陷阱            ← ❌ 错法 / ✅ 对法对照
  ## 模拟案例题          ← 完整题干 + 小问 + 参考答案 + 评分要点
  ## YYYY 年X半年真题     ← 真题原文 + 采分关键词 + 常见扣分点
```

**模拟题的质量要点**（这批材料做得比一般题库细）：
- 题干 800 字左右，带**具体业务数字**（QPS、可用性、团队规模、建设周期）
- 参考答案给出**评分要点表**（哪一项几分）
- 还有「**常见扣分点**」和「**高分技巧**」

---

## 怎么用

1. **先限时做**：模拟题建议严格 25 分钟作答（真实案例题每题 25 分）
2. **再对答案**：重点看「评分要点」里自己漏了哪一项
3. **背套路**：「答题模板」和「万能高分句」是可以直接迁移到其他题的
4. **回到真题**：做完专题后，去 `01-真题-按年份/` 找同年份的真题卷对练
