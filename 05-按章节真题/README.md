# 05-按章节真题 —— 按考点横向复习视图

> 这一层与 `01-真题-按年份/` **用途不同，不要混用**。

## 两层的区别

| | `01-真题-按年份/` | `05-按章节真题/`（本层） |
|---|---|---|
| 组织方式 | **按考期**（2025-上半年…） | **按考点章节**（设计模式、信息安全…） |
| 用途 | 按年刷整卷，模拟真实考试节奏 | 攻单个考点，一次打穿历年该考点的所有题 |
| 完整性 | 正本，题面尽量保真 | 汇编，可能只收录部分题目 |
| 同一道题 | 可能两边都有 | 可能两边都有 |

**两者不合并**：一道题在两个视图里的上下文不同（整卷 vs 考点聚合），
合并会破坏「按年刷卷」的能力。

## ⚠️ 三个已知限制（重要）

### 1. 未按章拆分文件
实测该 PDF **文字流不规整**：章标题与正文粘连、被分页切断。
自动切分会产生严重错位——我曾试出「设计模式 34 页、操作系统 14 页、而嵌入式 0 页」这种结果。
按「**宁可不拆，不可拆错**」的原则，保留完整原文 + 章节目录表。

### 2. 章节页码仅为近似
正文的解析文字里也会出现章名（比如讲解中提到"系统性能"），
自动定位**无法区分「章标题」与「正文提及」**，因此定位表里的页码
出现过「系统性能 ≈ p3」这类明显错误的条目。

**不要依赖该表精确跳转**，它是「本册覆盖哪些章」的提示，不是导航。

### 3. 内容有抽取噪声
PDF 逐字抽取，存在断句与个别错字。**重要结论请回原卷核对。**

## 怎么用这一层

**推荐做法：关键词搜索，而不是按页翻。**

```powershell
# 在本册里搜考点
python _脚本\search.py --only 章节 设计模式

# 跨全部层搜同一个考点
python _脚本\search.py 负载均衡
```

在 Obsidian 里直接 Ctrl+F 搜考点关键词（如「设计模式」「可靠性」），
本册的价值是**同一考点的历年题目集中在一处**，比重头翻十套真题省时间。

## 归档方式

新增同类「按考点汇编」时：
1. 用 `_脚本/import_chapters.py` 或直接复制抽取结果
2. 头部字段按 `00-元数据/元数据规范.md` 的「章节真题」类型填写
3. 运行 `python _脚本\validate.py` 校验
