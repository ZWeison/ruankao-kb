# 03-论文范文 —— 使用与归档说明

> 论文范文按你的要求**单独归类**。本目录与 `01-真题-按年份` 平级，互不混放。

## 为什么按「主题」分，而不是按「年份」分

结论：**按主题分**。

理由：你写论文时的真实思考顺序是"我要写微服务 / 我要写架构评估"，
很少会是"我要写 2021 年的题"。按主题归档，检索路径最短。

年份信息不丢 —— 它记在每个文件的头部 `对应年份` / `对应考期` 字段里，
`00-选题索引.md` 会自动生成"按主题"和"全部论题一览"两张表，年份随时可查。

## 文件命名

```
03-论文范文/<主题目录>/NNN-论题简称.md
```
示例：`03-论文范文/05-微服务与云原生/001-论微服务架构及其应用.md`

`NNN` 为该主题内的三位流水号。

## 头部字段

见 `00-元数据/元数据规范.md` 第 4 节（共 10 个字段）。

**最容易填错的两个字段：**

| 字段 | 为什么要认真填 |
|---|---|
| `是否考场原文` | 已核实：多个"范文分享"实为**培训机构或机构号自产**。题目是真的、文章不是考场答卷。填 `false`，提醒自己**只学结构、不学得分** |
| `范文类型` | `范文`（完整成文）/ `模板`（空壳结构）/ `提纲`（只列要点）。三者用途完全不同，混在一起会让你误判自己的写作水平 |

## 生成索引

归档后运行：
```powershell
python _脚本\build_index.py
```
会生成 `03-论文范文/00-选题索引.md`（按主题 + 全部论题一览两张表）。
