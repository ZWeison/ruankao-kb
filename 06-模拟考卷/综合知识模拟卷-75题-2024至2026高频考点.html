一、计算机组成与体系结构（7 题）

1. 计算机系统同类考点：24上·24下·25上
某计算机的 Cache 命中率为 95%，Cache 存取周期为 2 ns，主存存取周期为 20 ns。采用“先访问 Cache，未命中再访问主存”的串行方式，则平均访问时间约为（ ）。
答案：A　平均访问时间 = 0.95×2 + 0.05×(2+20) = 1.9 + 1.1 = 3.0 ns。注意未命中时先访问 Cache 的 2 ns 也要计入。
2. 计算机系统同类考点：24下·25上
某总线数据线宽度为 32 位，总线时钟频率为 100 MHz，每个时钟周期传送一次数据，则该总线的数据传输率约为（ ）。
答案：B　32 位 = 4 B，4 B × 100 M 次/秒 = 400 MB/s（即 3.2 Gb/s）。
3. 计算机系统同类考点：24上·25上
某系统由部件甲与“部件乙、丙并联”两部分串联组成，甲、乙、丙的可靠度均为 0.9，则该系统的可靠度为（ ）。
答案：C　并联部分可靠度 = 1-(1-0.9)² = 0.99；串联系统 = 0.9 × 0.99 = 0.891。
4. 计算机系统同类考点：24下·25上
某指令流水线分为 5 段，每段耗时 2 ns。在不考虑流水线建立时间的情况下，连续执行 100 条指令所需的时间为（ ）。
答案：D　完成 n 条指令需 (k+n-1)×Δt = (5+100-1)×2 = 208 ns。串行执行则需 100×5×2=1000 ns。
5. 计算机系统同类考点：24下·25上
对 8 位数据进行海明校验，至少需要（ ）位校验位。
答案：A　海明码需满足 2^k ≥ n+k+1。k=4 时 16 ≥ 8+4+1=13，成立；k=3 时 8 < 12，不成立。故至少 4 位。
6. 计算机系统同类考点：25上·25下
某系统页大小为 4 KB，物理内存为 8 GB，采用位示图管理空闲页框，则位示图至少占用（ ）。
答案：B　页框数 = 8 GB / 4 KB = 2³³ / 2¹² = 2²¹；位示图 2²¹ bit = 2¹⁸ B = 256 KB。
7. 计算机系统同类考点：24下·25上
关于 NOR Flash 与 NAND Flash 的描述，正确的是（ ）。
答案：C　NOR 可字节随机读、支持片内执行（XIP），适合作启动代码；NAND 按页读写、容量大、成本低，但需坏块管理与 ECC，一般作数据存储。

二、操作系统（7 题）

8. 操作系统同类考点：24下·25上·25下
一个正在运行的进程因等待 I/O 完成而进入阻塞态。当 I/O 操作完成后，该进程的状态将变为（ ）。
答案：D　I/O 完成只使进程具备运行条件，还需等待调度，故由阻塞态转为就绪态，不能直接转为运行态。
9. 操作系统同类考点：25下
某临界资源的互斥信号量当前值为 -2，其含义是（ ）。
答案：A　信号量值为负时，绝对值等于等待队列中的进程数；此时有 1 个进程在临界区内、2 个进程在等待。
10. 操作系统同类考点：25上
系统中有 5 个进程，每个进程最多需要 3 个同类资源。为保证系统一定不会发生死锁，该类资源至少需要（ ）个。
答案：B　最坏情况是每个进程各持有 2 个（共 10 个）并都在申请第 3 个；再多 1 个资源即可让某进程完成并释放，故至少 5×(3-1)+1 = 11 个。
11. 操作系统同类考点：24上·25上
某单处理机系统采用高响应比优先调度算法。当前有三个作业等待：甲已等待 10 ms、需运行 5 ms；乙已等待 3 ms、需运行 1 ms；丙已等待 8 ms、需运行 4 ms。下一个被调度的作业是（ ）。
答案：C　响应比 =（等待时间+要求服务时间）/ 要求服务时间：甲=(10+5)/5=3.0，乙=(3+1)/1=4.0，丙=(8+4)/4=3.0。乙最高，故选乙。
12. 操作系统同类考点：24下·25下
某进程分得 3 个页框，页面访问序列为 1,2,3,4,1,2,5,1,2,3,4,5。采用 LRU 置换算法（初始页框为空），缺页次数为（ ）。
答案：D　逐次模拟：前 7 次访问均缺页；随后访问 1、2 命中；访问 3、4、5 各缺页一次。合计 10 次缺页。
13. 操作系统同类考点：25下
某文件系统采用树形目录，当前工作目录为 /usr/local/etc。要访问文件 /usr/bin/tool，使用相对路径应写作（ ）。
答案：A　从 /usr/local/etc 上跳两级到 /usr，再进入 bin/tool，故相对路径为 ../../bin/tool；以“/”开头的是绝对路径，且题中绝对路径写法本身与目标不符。
14. 操作系统同类考点：25上
三个周期任务 T1、T2、T3 的周期分别为 10 ms、20 ms、50 ms，采用速率单调调度（RMS），优先级从高到低依次为（ ）。
答案：B　RMS 按周期分配优先级：周期越短、截止期越紧，优先级越高。故 T1 > T2 > T3。

三、数据库系统（8 题）

15. 数据库同类考点：24下·25上
数据库系统三级模式中，外模式/模式映像的存在保证了数据的（ ）。
答案：C　外模式/模式映像使模式改变时只需调整映像、不必改应用程序，保证逻辑独立性；模式/内模式映像保证物理独立性。
16. 数据库同类考点：25下
设 R 和 S 是同类关系，则关系表达式 R-(R-S) 等价于（ ）。
答案：D　R-(R-S) = R∩S，这是集合运算的基本恒等式。
17. 数据库同类考点：24下
关系 R(a,b,c) 与 S(b,c,d) 进行自然连接，结果关系的列数为（ ）。
答案：A　自然连接在公共属性 b、c 上做等值连接并去掉重复列，结果为 a,b,c,d 共 4 列。
18. 数据库同类考点：24下·25上
关系 R(A,B,C,D)，函数依赖集 F={A→B, B→C, C→D}，则 R 的候选码是（ ）。
答案：B　A 的闭包 A⁺ = {A,B,C,D}，且 A 不可再约简，故 A 为候选码；B、C、D 均不能决定全部属性。
19. 数据库同类考点：24下·25上
关系 R(职工号, 职工姓名, 部门号, 部门名称)，其中职工号→职工姓名、职工号→部门号、部门号→部门名称。该关系最高满足（ ）。
答案：C　码为职工号，非主属性均完全依赖于码，满足 2NF；但存在职工号→部门号→部门名称的传递依赖，不满足 3NF。
20. 数据库同类考点：24下·25下
事务 T1 修改了某行数据但尚未提交，事务 T2 读取到该行修改后的值，随后 T1 回滚。这种现象称为（ ）。
答案：D　读到其他事务未提交且最终回滚的数据即脏读；不可重复读是同一事务内两次读同一行结果不同；幻读是两次查询返回的行数不同。
21. 数据库同类考点：25下
关于两阶段锁协议（2PL），描述正确的是（ ）。
答案：A　2PL 分扩展（加锁）与收缩（解锁）两阶段，可保证可串行化，但不能避免死锁（如交叉等待）。
22. 数据库同类考点：25下
数据库设计过程中，将 E-R 图转换为关系模式并进行规范化处理，属于（ ）阶段的工作。
答案：B　概念设计产出 E-R 图；逻辑设计把 E-R 图转换为关系模式并规范化；物理设计确定存储结构与索引。

四、计算机网络（5 题）

23. 计算机网络同类考点：24下·24上
在 OSI 参考模型中，路由器工作于（ ）。
答案：C　路由器依据 IP 地址进行分组转发与路由选择，属网络层设备；二层交换机属数据链路层，中继器/集线器属物理层。
24. 计算机网络同类考点：24下
下列协议中，属于传输层的是（ ）。
答案：D　UDP 与 TCP 同属传输层；ICMP、ARP 属网络层，HTTP 属应用层。
25. 计算机网络同类考点：25下
某子网掩码为 255.255.255.240，则该子网中可分配给主机的地址数量为（ ）。
答案：A　240 = 11110000，主机位 4 位，共 2⁴=16 个地址，去掉网络地址与广播地址，可用 14 个。
26. 计算机网络同类考点：24上·25上
某无噪声信道带宽为 4 kHz，采用 16 种不同的信号状态传输数据，则其最大数据传输率约为（ ）。
答案：B　奈奎斯特定理：C = 2W·log₂V = 2×4000×log₂16 = 2×4000×4 = 32 kbps。
27. 计算机网络同类考点：25上
在 RESTful 接口中，对资源进行部分更新应使用的 HTTP 方法是（ ）。
答案：C　PUT 用于整体替换资源（幂等），PATCH 用于部分更新，GET 查询，HEAD 只取响应头。

五、软件工程与开发方法（8 题）

28. 软件工程同类考点：24下·25上
某大型软件项目需求不明确、技术风险高，且需要边开发边验证，最适合采用（ ）。
答案：D　螺旋模型以风险分析为核心，每轮迭代都包含风险识别与消解，适合大型、高风险、需求不清的项目。
29. 软件工程同类考点：25上
CMMI 成熟度模型的第 4 级是（ ）。
答案：A　五级依次为：初始级、已管理级、已定义级、量化管理级、优化级。
30. 软件工程同类考点：25下
关于 Scrum 的描述，错误的是（ ）。
答案：B　Sprint 期间应保护团队不受干扰，新需求进入产品待办列表并留待后续 Sprint 规划，不能随意插入当前 Sprint。
31. 软件工程同类考点：25下·25上
某模块内的处理元素必须按特定次序执行，且前一个元素的输出是后一个元素的输入，该模块的内聚类型是（ ）。
答案：C　顺序内聚强调“有序且数据流串联”；功能内聚是各元素共同完成单一功能；通信内聚是操作同一数据集；逻辑内聚是逻辑相似、可选择执行。
32. 软件工程同类考点：25下
下列耦合类型中，模块间联系最弱（耦合度最低）的是（ ）。
答案：D　耦合由弱到强：非直接 < 数据 < 标记 < 控制 < 外部 < 公共 < 内容。数据耦合只传简单数据参数，联系最弱。
33. 软件工程同类考点：25上·24下
在数据流图中，两个数据流之间用“*”号连接，表示它们之间是（ ）关系。
答案：A　数据流图中“*”表示与（同时发生），“+”表示或，“⊕”表示异或（互斥，只能取其一）。
34. 软件工程同类考点：24上·25上
在 UML 用例图中，下列不属于用例之间关系的是（ ）。
答案：B　用例之间存在包含、扩展与泛化关系；聚合是类之间的关系，用于表达整体与部分。
35. 软件工程同类考点：25下
逆向工程的主要目的是（ ）。
答案：C　逆向工程分析程序以恢复设计信息；再工程 = 逆向工程 + 重构 + 前向工程，目的是改善系统而非替代需求分析。

六、软件测试（5 题）

36. 软件测试同类考点：25上·24下
下列测试方法中，不属于黑盒测试方法的是（ ）。
答案：D　基本路径测试属于白盒测试；等价类、边界值、因果图、判定表、错误推测均为黑盒方法。
37. 软件测试同类考点：25上·24下
下列白盒测试覆盖准则中，覆盖能力最强的是（ ）。
答案：A　覆盖强度大致为：语句 < 判定 < 条件组合 < 路径。路径覆盖要求执行所有可能路径，最强。
38. 软件测试同类考点：25下
软件测试的标准流程中，正确的顺序是（ ）。
答案：B　先验证单元，再验证接口与集成，然后做系统级验证，最后由用户验收。
39. 软件测试同类考点：25上
回归测试的主要目的是（ ）。
答案：C　回归测试在缺陷修复或变更后执行，重点验证“改动没有破坏原有功能”，通常复用原有用例并补充针对性用例。
40. 软件测试同类考点：25上·25下
关于软件测试与调试，说法错误的是（ ）。
答案：D　调试成功只说明已发现的错误被修正，不能证明软件无其他错误；测试只能证明缺陷存在，不能证明缺陷不存在。

七、软件架构设计（11 题）

41. 架构设计同类考点：24下·25上
在 4+1 视图模型中，关注并发性、同步与性能等需求的视图是（ ）。
答案：A　逻辑视图对应功能需求；进程视图关注并发、同步与性能；开发视图关注模块与包的组织；物理视图关注软件到硬件的部署。
42. 架构设计同类考点：24上·25上
管道-过滤器风格最适合用于（ ）。
答案：B　管道-过滤器把处理分解为独立过滤器，通过数据流管道串联，适合编译、图像处理、数据转换等批处理；缺点是不适合交互式应用。
43. 架构设计同类考点：25上
在黑板体系结构中，控制构件的主要职责是（ ）。
答案：C　黑板结构由知识源、黑板（共享数据）与控制三部分组成，控制构件依据黑板状态决定激活哪个知识源。
44. 架构设计同类考点：25上
事件驱动（隐式调用）架构风格的主要缺点是（ ）。
答案：D　隐式调用使构件松耦合、易扩展，但控制流不显式，难以推理整体行为，且不能保证事件处理顺序。
45. 架构设计同类考点：25下
解释器体系结构通常由四部分组成，即解释引擎、被解释程序的存储区、（ ）以及记录解释执行进度的数据结构。
答案：A　解释器四要素：解释引擎、被解释代码、解释器内部状态（当前工作状态）、记录执行进度的数据结构。
46. 架构设计同类考点：24下
在进程通信体系结构风格中，构件之间的连接件是（ ）。
答案：B　进程通信风格以独立进程为构件，通过显式的消息传递（同步或异步）协作；管道是管道-过滤器风格的连接件。
47. 架构设计同类考点：24下
基于架构的软件开发方法（ABSD）中，体系结构需求主要来源于（ ）。
答案：C　ABSD 把体系结构需求归结为三类驱动因素：系统的质量目标、系统的商业目标、系统开发人员的商业目标。
48. 架构设计同类考点：24下·25下
按教材划分，下列不属于特定领域软件体系结构（DSSA）参与角色的是（ ）。
答案：D　DSSA 的四类角色为领域专家、领域分析师、领域设计人员、领域实现人员；最终用户不是其定义的角色。
49. 架构设计同类考点：24下·25下
使用效用树对质量属性场景排序时，采用的两个维度是（ ）。
答案：A　效用树按“业务重要性（对系统成功的重要性）”和“技术难度（实现难度）”两个维度给场景打 (H/M/L)，据此确定架构关注点优先级。
50. 架构设计同类考点：25下
在架构评估中，将加密强度由 128 位提高到 256 位会提升安全性但增加处理时间。该决策点属于（ ）。
答案：B　该决策同时影响安全性（正）与性能（负），是多质量属性之间的折中，故为权衡点；敏感点是影响单一质量属性的关键决策。
51. 架构设计同类考点：25上
微服务架构中，断路器（Circuit Breaker）的三种状态是（ ）。
答案：C　Closed 正常放行并统计失败率；失败率超阈值转 Open 直接拒绝；超时后进入 Half-Open 放行少量请求探测，成功则 Closed，失败则重新 Open。

八、信息安全（5 题）

52. 信息安全同类考点：24上·24下
信息安全的基本要素不包括（ ）。
答案：D　信息安全五要素为机密性、完整性、可用性、可控性、不可否认性；可移植性是软件质量属性。
53. 信息安全同类考点：25下
关于数字签名的描述，正确的是（ ）。
答案：A　数字签名用发送方私钥对报文摘要签名，接收方用其公钥验证，可保证完整性、身份真实性与不可否认性，但不提供机密性。
54. 信息安全同类考点：25下
下列不属于 PKI 组成部分的是（ ）。
答案：B　PKI 由 CA、RA、证书库、证书撤销（CRL/OCSP）、密钥备份与恢复、应用接口等组成；IDS 属于安全防护设备，不是 PKI 组件。
55. 信息安全同类考点：24下
防范 SQL 注入最有效的措施是（ ）。
答案：C　参数化查询让输入始终作为数据而非 SQL 语法的一部分，从根源上消除注入；转义易被绕过，长度限制与改端口只是辅助。
56. 信息安全同类考点：24上
依据《计算机信息系统安全保护等级划分准则》，计算机信息系统安全保护等级的最高级是（ ）。
答案：D　五级依次为：用户自主保护级、系统审计保护级、安全标记保护级、结构化保护级、访问验证保护级。

九、新技术与前沿趋势（7 题）

57. 新兴技术同类考点：24上·26上

十、项目管理（3 题）

64. 项目管理同类考点：24上·24下·25上
某项目活动及依赖关系如下：A(3 天)、B(4 天) 无紧前活动；C(2 天) 紧前为 A；D(5 天) 紧前为 A、B；E(3 天) 紧前为 C、D；F(2 天) 紧前为 D；G(4 天) 紧前为 E、F。该项目的最短工期为（ ）。
答案：D　关键路径为 B→D→E→G：4+5+3+4=16 天；其余路径 A-C-E-G=12、A-D-E-G=15、A-D-F-G=14、B-D-F-G=15，均不超过 16 天。
65. 项目管理同类考点：24下·25上
某项目当前 PV=100 万元，EV=80 万元，AC=90 万元，则项目状态是（ ）。
答案：A　SPI=EV/PV=0.8<1，进度落后；CPI=EV/AC≈0.89<1，成本超支。
66. 项目管理同类考点：24下

十二、应用数学（2 题）

69. 数学同类考点：24下·25上·25下
某单位 100 名员工中，会 Java 的 45 人，会 Python 的 53 人，会 C++ 的 55 人；既会 Java 又会 Python 的 28 人，既会 Python 又会 C++ 的 35 人，既会 Java 又会 C++ 的 32 人，三种都会的 20 人。则三种语言都不会的人数为（ ）。
答案：A　容斥原理：至少会一种 = 45+53+55-28-35-32+20 = 78；故都不会 = 100-78 = 22 人。
70. 数学同类考点：25上
已知约束条件 x≥1，y≥x，x+y≤6，则 y/x 的最大值是（ ）。
答案：B　可行域中 y≤6-x，故 y/x ≤ (6-x)/x = 6/x-1，在 x=1 时取最大 5（此时 y=5）。
