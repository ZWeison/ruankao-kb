### 交互功能

- ⏱ **倒计时**：150 分钟，可暂停/重置，剩余 10 分钟变红
- ✍️ **答题框**：每题一个输入区，实时显示字数
- 💾 **自动保存**：输入即写入浏览器 localStorage，关页面不丢（`Ctrl+S` 也可手动存）
- 👁 **参考答案折叠**：默认隐藏，答完再展开，避免边看边抄
- 🎯 **自评打分**：每题可填自评得分，工具栏实时汇总（满分 125）
- 🖨 **打印/导出 PDF**：会自动展开参考答案一起打印

## 怎么用

```
1. 双击 HTML 文件，用浏览器打开
2. 点「开始计时」，按真实考场节奏作答
3. 每题写完 → 点该题下方「显示本大题参考答案」
4. 对照参考答案里的「采分点」给自己打分
5. 点「打印 / 导出 PDF」留存纸质版
```

**实战提醒**：真实案例考试是 **5 选 3（第 1 题必答 + 其余选 2）**，满分 75 分、90 分钟。
本卷 5 题全做是为了把考点练全；临近考试时建议按 5 选 3 模拟。
