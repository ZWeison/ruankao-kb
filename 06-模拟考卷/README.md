## 怎么用

**综合知识卷**

```
1. 双击 HTML 文件，用浏览器打开
2. 点「开始计时」，150 分钟内做完 75 题
3. 交卷 → 看总分与「按板块正确率」表，定位薄弱板块
4. 逐题看解析（错题选项已标红，正确项标绿）
5. 点「打印 / 导出 PDF」留存纸质版
```

**案例分析卷**

```
1. 双击 HTML 文件，用浏览器打开
2. 点「开始计时」，按真实考场节奏作答
3. 每题写完 → 点该题下方「显示本大题参考答案」
4. 对照参考答案里的「采分点」给自己打分
5. 点「打印 / 导出 PDF」留存纸质版
```

**实战提醒**：

- 综合知识：**75 题、75 分、150 分钟、60 分及格**，全部为单选，不倒扣分，不留空。
- 案例分析：**5 选 3（第 1 题必答 + 其余选 2）**，满分 75 分、90 分钟。两卷 5 题全做是为了把考点练全，临近考试建议按 5 选 3 模拟。
