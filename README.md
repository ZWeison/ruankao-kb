## 快速开始

1. **看规范** → `00-元数据/元数据规范.md`
2. **看有哪些年份真的开考** → `00-元数据/考试期次总表.md`
3. **看资料从哪来** → `00-元数据/来源清单.md`
4. **放真题** → `01-真题-按年份/YYYY-考期/`（用 `00-元数据/_模板/` 下的模板）
5. **放范文** → `03-论文范文/<主题目录>/`
6. **校验 + 生成索引**：
   ```powershell
   python _脚本\validate.py
   python _脚本\build_index.py
   ```

## 三个脚本（在 `D:\软考知识库` 下运行）

```powershell
# 1. 校验：所有文件的 YAML 头部是否合规、文件名与内容是否一致
python _脚本\validate.py

# 2. 生成索引：重算 02-按题型索引\ 与 00-元数据\exams.json
python _脚本\build_index.py

# 3. 全文检索
python _脚本\search.py ATAM                    # 关键词
python _脚本\search.py --tag 架构评估           # 按考点标签
python _脚本\search.py --kind 回忆版 --year 2023-2025
python _脚本\search.py --only 范文 微服务       # 只搜范文
python _脚本\search.py --tags                  # 标签统计
python _脚本\search.py --stats                 # 整体统计
python _脚本\search.py --dubious               # 存疑题清单（考前重点核对）
```

**每次新增或修改文件后，按 `validate → build_index` 顺序跑一遍。**

## 三条硬规则

1. **不合并不同回忆版。** 2023 下半年综合知识有 A 卷 65 题 / B 卷 75 题两套独立版本，
   题序题量都不同，各自成文件，`-回忆版A` / `-回忆版B` 标记。
2. **模拟题不进 `01-真题-按年份`。** `来源类型` 必须是 `模拟题`，放 `99-待校对` 或独立目录。
3. **不改 `04-原始资料`。** 那是凭证；改了就没法回溯核对。

## 两个必须理解的字段

这套库的价值，一半在这两个字段上：

| 字段 | 作用 |
|---|---|
| `来源类型` + `是否官方` | **防止把模拟题当真题背。** 官方从不公布真题；2023 机考后全是回忆版 |
| `答案可信度` + `含解析` | **防止把网友自答的错答案当标准答案。** 有的公开资料里作者自己都标了"这个有疑问" |

判断资源真伪的标尺（来自一位案例解析作者的原文）：
> 「机考后真题变化较大…**机考后真题不好拿出来，所有市面上真题较少，几乎没有。**」

**凡宣称提供 2023 年之后"完整权威真题 + 标准答案"的，一律应当怀疑。**

## 怎么用这个库

| 场景 | 怎么做 |
|---|---|
| **看真题论题** | 打开 `01-真题-按年份/2025-上半年/2025-上半年-论文.md`，就是当期 4 个论题与写作要求 |
| **找同主题范文** | `03-论文范文/00-选题索引.md` 按主题列出全部 39 篇；或直接看 `03-论文范文/05-微服务与云原生/` 这类主题目录 |
| **拆范文结构** | 每篇都有 `## 摘要` + `## 正文` 分段。重点看：摘要怎么压到 280—300 字、正文怎么用「问题—方案—效果」三段式 |
| **自己写 → 找 AI 批改** | 写完把文件路径给我，我对着同主题范文逐段给意见 |
| **错题/素材积累** | `90-我的复习/我的论文/` 放自己写的稿；`错题本/` 记薄弱点 |
| **AI 检索** | 文件都带结构化头部，可直接让我按主题/年份检索、统计、批改 |
| **做模拟卷** | 打开 `06-模拟考卷/案例分析模拟卷-五题全卷.html`，带计时、答题框、自评打分与参考答案折叠 |
