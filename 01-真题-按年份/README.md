# 01-真题-按年份 —— 正本层

> 这里是**正本**。所有真题正文只在这里存一份，其它地方都是指向这里的索引。

## 归档方式

1. 复制 `00-元数据/_模板/` 下对应科目的模板
2. 放到 `YYYY-考期/` 目录，命名为 `YYYY-考期-科目.md`
3. 填好 YAML 头部（15 个字段，见 `00-元数据/元数据规范.md` 第 3 节）
4. 运行 `python _脚本\validate.py` 校验
5. 运行 `python _脚本\build_index.py` 更新索引

格式参考可直接看 `00-元数据/_示例/` 下两个样例文件。

## 目录命名

| 规则 | 示例 |
|---|---|
| `YYYY-考期/` | `2025-上半年/`、`2023-下半年/` |
| `YYYY-考期-科目.md` | `2025-上半年-综合知识.md` |

**科目固定三个**：`综合知识`（选择题）｜`案例分析`（案例题）｜`论文`（论文题）

## ⚠️ 建目录前必看

**2016—2023 年只在【下半年】开考**，没有上半年考试。
不要凭习惯建 `2020-上半年/` 这种不存在的目录。

开考情况以 `00-元数据/考试期次总表.md` 为准；`validate.py` 也会自动拦截这类错误。

## 多套回忆版怎么处理

机考后同一次考试可能出现题序、题量都不同的多套回忆版。
**各自成文件，绝不合并**，文件名加版本标记：

```
2023-下半年-综合知识-回忆版A.md    # 65 题
2023-下半年-综合知识-回忆版B.md    # 75 题
```

合并会造出"第三个版本"，既不等于 A 也不等于 B，是错的。

## 什么不能放进来

| 内容 | 该放哪 |
|---|---|
| 模拟卷、预测卷、模考卷 | `99-待校对/`，且 `来源类型: 模拟题` |
| 来源不明的真题 | `99-待校对/` |
| 论文**范文** | `03-论文范文/`（这里只放论文**论题**） |
| PDF 原件 | `04-原始资料/历年真题PDF/` |
