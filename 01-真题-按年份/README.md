## 论文卷里放什么

只放**当期 4 个论题 + 写作要求（三问）**，不放范文——范文统一归到 `03-论文范文/`。

```markdown
## 试题一：论XXX

（题干导语……）

请围绕"论XXX"论题，依次从以下三个方面进行论述：

1. 概要叙述你参与管理和开发的软件项目以及你在其中承担的主要工作。
2. ……
3. ……
```

## 新增文件怎么做

1. 复制 `00-元数据/_模板/真题模板-论文.md`
2. 放到 `YYYY-考期/`，命名为 `YYYY-考期-论文.md`
3. 填好 YAML 头部（字段见 `00-元数据/元数据规范.md`）
4. `python _脚本\validate.py` 校验
5. `python _脚本\build_index.py` 更新索引

## ⚠️ 建目录前必看

**2016—2023 年只在【下半年】开考**，没有上半年考试。
虽然这些考期目前不收录，但若将来恢复，不要凭习惯建 `2020-上半年/` 这种不存在的目录。

开考情况以 `00-元数据/考试期次总表.md` 为准；`validate.py` 会自动拦截这类错误。

## 多套回忆版怎么处理

机考后同一次考试可能出现题序、题量都不同的多套回忆版。
**各自成文件，绝不合并**，文件名加版本标记：

```
2023-下半年-综合知识-回忆版A.md
2023-下半年-综合知识-回忆版B.md
```

合并会造出"第三个版本"，既不等于 A 也不等于 B，是错的。
